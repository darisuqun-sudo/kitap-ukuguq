# «كىتابخۇمار» (KitabXumar) - Desktop PDF كىتاب ئوقۇغۇچ

«كىتابخۇمار» — كومپيۇتېر ئۈچۈن مەخسۇس لايىھەلەنگەن، ئوڭدىن سولغا (RTL) ئۇيغۇرچە يېزىق تەرتىپىگە تولۇق ماسلاشقان، كۆپ تىللىق زامانىۋى PDF كىتاب ئوقۇش ئەپ دېتالى.

---

## ئاساسىي ئالاھىدىلىكلىرى

1. **ئوڭدىن سولغا (RTL) تەبىئىي كۆرۈنمە يۈز:**
   - پۈتۈن كۆرۈنمە يۈز ئۇيغۇرچە يېزىق ئادىتى بويىچە ئوڭدىن سولغا تىزىلغان.
   - كىتاب تىزىملىكى (Sidebar) تەبىئىي ھالدا ئوڭ تەرەپتە تۇرىدۇ.
2. **تاش مۇقاۋا كىچىك رەسىمى (Cover Thumbnails):**
   - ھەر بىر PDF كىتابنىڭ بىرىنچى بېتىدىن نەق مەيداندا ئاپتوماتىك سۈپەتلىك مۇقاۋا رەسىمى ھاسىل قىلىنىپ چىقىدۇ.
3. **ئوقۇغان يېرىدىن داۋاملاشتۇرۇش (Auto-Resume Reading):**
   - كىتابنى تاقاپ قايتا ئاچقاندا، ئەڭ ئاخىرقى قېتىم ئوقۇغان بەت نومۇرى ۋە كۆرۈش نىسبىتى ئاپتوماتىك ئەستە ساقلىنىپ شۇ يەردىن ئېچىلىدۇ.
4. **رەسىمگە كېسىپ تارتىش قورالى (Screenshot Snipper):**
   - «📸 رەسىمگە تارتىش» تۈگمىسىنى بېسىپ، بەتتىكى خالىغان بۆلەك ياكى جۈملىنى چاشقىنەك بىلەن سىزىپ رەسىمگە تارتىۋالغىلى بولىدۇ.
   - تارتىلغان رەسىمنى بىۋاسىتە چاپلاش تاختىسىغا (Clipboard) نۇسخىلاش ياكى PNG شەكلىدە ساقلاشقا بولىدۇ.
5. **كۆپ تىللىق سىستېما:**
   - 🇦🇫 ئۇيغۇرچە (ئاساسلىق - RTL)
   - 🇸🇦 ئەرەبچە / العربية (RTL)
   - 🇹🇷 تۈركچە / Türkçe (LTR)
   - 🇬🇧 ئىنگلىزچە / English (LTR)
6. **كۆرۈنۈش ھالەتلىرى:**
   - ☀️ كۈندۈز ھالىتى (Light)
   - 🌙 كېچە ھالىتى (Dark)
   - ☕ قەغەز رەڭگى (Sepia / كۆز ئاسراش)
7. **كىتاب ئىچىدىن ئىزدەش (Search in Book):**
   - كىتاب تېكىستلىرى ئىچىدىن خالىغان سۆزنى ئىزدەش ۋە ماس كەلگەن بەتكە بىر چېكىش بىلەن ئۆتۈش.
8. **خەتكۈچلەر (Bookmarks):**
   - مۇھىم بەتلەرگە خەتكۈچ قويۇش ۋە تېز قايتىپ كېلىش.

---

## دېتالنى قوزغىتىش ئۇسۇلى

### ئۇسۇل 1: چاشقىنەك بىلەن بىۋاسىتە قوزغىتىش
قىسقۇچ ئىچىدىكى `start_kitap.bat` ھۆججىتىنى قوش چەكسىڭىزلا دېتال قوزغىلىدۇ.

### ئۇسۇل 2: بۇيرۇق قۇرى ئارقىلىق قوزغىتىش
```bash
# Electron Desktop دېتالى شەكلىدە قوزغىتىش:
npm start

# ياكى تور كۆرگۈچ (Web Preview) شەكلىدە قوزغىتىش:
npm run dev:vite
```

## تۈر قۇرۇلمىسى

- `src/components/Header.tsx` — تېز مەشغۇلات تاختىسى (رەسىمگە تارتىش، تىل، ھالەت، بەت ئالماشتۇرۇش)
- `src/components/BookSidebar.tsx` — ئوڭ تەرەپ كىتاب تىزىملىكى ۋە مۇقاۋا رەسىملىرى
- `src/components/PdfViewer.tsx` — ئىلغار PDF رەندەرلەش ماتورى
- `src/components/ScreenshotModal.tsx` — رەسىمگە تارتىش ۋە چاپلاش تاختىسىغا نۇسخىلاش قورالى
- `src/components/SearchModal.tsx` — كىتاب ئىچىدىن ئەقلىي ئىزدەش بۆلىكى
- `src/services/db.ts` — يەرلىك ساندان (ئوقۇلغان ئورۇن ۋە كىتابلارنى مەڭگۈلۈك ساقلاش)
- `src/services/pdf.ts` — PDF بىر تەرەپ قىلىش ۋە مۇقاۋا ھاسىللاش
- `src/i18n/translations.ts` — كۆپ تىللىق تەرجىمە ۋە RTL تىزىملىكى
- `electron/main.js` — ئۈستەلئۈستى دېتال ئاساسىي لىنىيەسى
